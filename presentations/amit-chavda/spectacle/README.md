# Spectacle deck

`index.html` is a Spectacle one-page deck (React + htm via esm.sh import map, same pattern as
`spectacle/examples/one-page`). Open it in a browser: arrow keys to move, `Alt/Option+P` presenter mode with notes.
No build needed. To move it into a full Spectacle project: `npx create-spectacle` and paste the slides.
