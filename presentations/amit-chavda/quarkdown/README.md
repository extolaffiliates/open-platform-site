# Quarkdown deck

Compile (Java 17+, Quarkdown CLI installed by `presentation-toolkit/install.sh`):

    quarkdown c main.qd -p            # HTML slides (reveal.js), press S for speaker notes
    quarkdown c main.qd --pdf         # PDF (needs Chromium)
